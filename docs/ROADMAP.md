# Roadmap

Not commitments; ordered roughly by value.

- Authentication events view. (Configuration changes now appear on *What changed?* with their own evidence page.)
- Per-user firewall (site) restrictions, enforced on every page and API rather than in one view.
- Detection-test scenarios for IDS and firewall-log rules (traffic rules are covered today).
- Server page DNS card (transport + names with correlation confidence).
- Optional adapters: LibreNMS (interface counters), NetBox (inventory and prefixes).
- External exposure checks (certificate expiry for published services) — only against your own addresses, opt-in.
- Health notifications (off by default) once destinations are tested.
- Installer script for a fresh host; restore drill on a fresh VM.
